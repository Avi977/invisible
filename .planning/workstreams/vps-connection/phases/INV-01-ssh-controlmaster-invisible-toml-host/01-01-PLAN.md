Decision A — Two ControlMaster layers coexisting (no consolidation, document the split):

`~/.ssh/config` carries `ControlPath ~/.ssh/cm-%r@%h:%p` `ControlPersist 10m` for the user's interactive `ssh srv982719` from any shell (including app-spawned panes via `lib/pty_server.py` ssh variant in Phase 3).

These are intentionally DIFFERENT sockets — the dashboard daemon's walker shouldn't share a control socket with the user's interactive sessions (a `~/.ssh/cm-*` socket can be torn down by the user closing their shell; the dashboard wants a dedicated isolated socket that survives across user sessions). The planner is NOT consolidating these — both should coexist. The README must document this split so a future reader doesn't try to "fix" it by collapsing to one path.

def check_ssh(cfg: dict) -> tuple[str, str, str]:
    vps = (cfg.get("vps") or {})
    host = vps.get("host")
    if not host:
        return ("ssh: vps.host", WARN, "no vps.host configured")  # CURRENT — keep semantically
